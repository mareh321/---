# Работа с проектом

- Графическое приложение для Windows на Rust и egui находится в `src/desktop.rs`.
  Основной исполняемый файл называется `list-desktop.exe`.
- Перед изменением движка проверьте зависимости между регионами и порядок
  вычисления. Числовые входы обновляют зависимые регионы, а структурная
  правка пересобирает лист. Старые численные результаты XMCD служат эталоном
  для сверки.
- Сохраняйте исходные XMCD и XMCDZ. По Ctrl+S приложение пишет отдельную
  копию, сохраняет данные разметки и удаляет устаревшие расчётные кэши.
- Используйте MSVC и стабильный Rust. Запускайте `cargo fmt --all -- --check`
  и `cargo test --locked --features desktop --all-targets`. После сборки
  `cargo build --release --locked --features desktop --bins` запустите
  `scripts/verify.ps1` из PowerShell.
- Для проверки окна откройте пустой лист и пример `list-desktop.exe --example`.
  Проверьте ввод `x := 2`, вывод `x^2 =`, редактирование графика и повторное
  открытие сохранённой копии.
- Перед началом следующей задачи прочитайте [STATUS.md](STATUS.md)
  и [ROADMAP.md](ROADMAP.md).
- По просьбе владельца публикуйте каждую проверенную версию «Листа»
  в `main` репозитория `origin` на GitHub. Перед отправкой запустите проверки
  по затронутым функциям. После отправки сверьте коммит в удалённой ветке
  и укажите ссылку на него в отчёте.
