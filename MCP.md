# Подключение ИИ-агента к «Листу»

MCP-сервер запускается как отдельный процесс `list-mcp.exe` по stdio.
Клиент запускает его сам и обменивается с ним JSON-RPC через stdin и stdout.
На одно подключение приходится один активный расчётный лист. Сервер умеет
открывать и создавать листы, вычислять формулы, изменять входы, редактировать
регионы и сохранять XMCD, CSV и отчёты.

## Настройка клиента

Для клиента с JSON-конфигурацией формата `mcpServers` укажите полный путь.
Необязательный аргумент `--sheet` открывает указанный файл при запуске.

```json
{
  "mcpServers": {
    "list-rs": {
      "command": "C:\\Tools\\list-rs\\bin\\list-mcp.exe",
      "args": ["--sheet", "C:\\Calculations\\Рабочая копия.xmcd"]
    }
  }
}
```

Для пустого листа задайте `"args": []`. Сервер поддерживает stdio-версии MCP
`2024-11-05`, `2025-03-26`, `2025-06-18` и `2025-11-25` с
`initialize` / `notifications/initialized`. Современным клиентам с
автоматическим выбором протокола нужен доступный режим handshake.

## Работа с окном приложения

Откройте одну и ту же рабочую копию XMCD в сервере и `list-desktop.exe`.
После изменения формул или входов агент вызывает `export_xmcd`. Для обновления
существующей рабочей копии он передаёт её путь и `overwrite: true`.
Графическое приложение перечитывает изменившийся файл после сохранения
агентом. Если в окне есть несохранённые правки, оно показывает предупреждение.
Команда «Перезагрузить с диска» доступна через Ctrl+R.

Без `overwrite: true` сервер сохраняет только новый файл. После сохранения
он работает с сохранённой копией. Если рабочий файл уже изменили на диске,
сервер предложит открыть его заново или сохранить отдельную копию.
Листы с относительными подключениями сохраняйте в папке исходного листа.
Для явного отказа от несохранённых правок на стороне MCP передайте
`discard_unsaved: true` в `new_sheet` или `open_sheet`.

## Сборка и проверка

```powershell
cargo build --locked --release --features mcp --bin list-mcp
python .\scripts\check_mcp.py .\target\release\list-mcp.exe
cargo test --locked --features desktop --all-targets
```

Графическая сборка `--features desktop --bins` включает MCP-сервер.
Для прогона экспорта PDF через установленный браузер добавьте `--pdf`
к команде проверки.
