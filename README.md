# Лист на Rust

Расчётная среда для Windows x64. Открывает листы Mathcad 15 в форматах XMCD
и XMCDZ. После изменения входа пересчитываются зависимые регионы.

[Скачать ранее выпущенную версию 0.5 для Windows x64](releases/list-rs-0.5-windows-x64.zip).
Чтобы запустить текущую ревизию с изменениями Gemini, соберите
`target/release/list-desktop.exe` по командам ниже.

Для продолжения разработки в новом чате откройте этот репозиторий и укажите
[AGENTS.md](AGENTS.md), [STATUS.md](STATUS.md) и [ROADMAP.md](ROADMAP.md).
В [текущем состоянии](STATUS.md) описаны возможности и ограничения этой
ревизии. План содержит исходное сравнение 0.5 с Mathcad 15 и критерии
проверки. Архивы предыдущих версий лежат в [releases](releases/).

## Графическое окно

Запустите `list-desktop.exe`. Откроется пустой лист.
Щёлкните в нужном месте, введите `x := 2` и нажмите Enter. Затем введите
`x^2 =` и нажмите Enter. На листе появится результат 4. Кнопки «+ Формула»,
«+ Текст» и «+ График» вставляют выбранный тип региона в отмеченное место.

График можно построить по выражению от `x` или по паре массивов, определённых
выше графика. В поле выражения можно указать до четырёх функций через точку
с запятой, например `sin(x); cos(x)`. Параметры графика сохраняются в копии
листа и воспроизводятся в «Листе на Rust». Кнопка «Пример» открывает лист с графиком.

Свой лист можно открыть через кнопку «Открыть…», Ctrl+O или перетаскиванием
файла в окно. Для широких листов есть режим «По ширине» и горизонтальная
прокрутка. Выбор региона раскрывает формулу, результат или содержимое массива.
Формулы отображаются компактной математической записью с размещением по
координатам из файла.

F2 или двойной щелчок открывает редактирование на листе. Палитра вставляет
дроби, корни, степени и матрицы. В матрице Tab и Shift+Tab перемещают
каретку между ячейками, стрелки влево и вправо работают с символами
внутри ячейки. Меню «Правка» содержит команды копирования и отмены.
В меню «Файл» доступны CSV, HTML-отчёт и фоновый экспорт PDF через Edge
или Chrome.

| Запись | Действие |
|---|---|
| `p := 2 * F / S` | Определение или изменение формулы |
| `sqrt(a^2 + b^2) =` | Отдельный вывод результата |
| `f(x) := x^2 + 1` | Определение функции |
| `z := -1.5 + 1i` | Комплексное число |
| `k := 0..28`, `range(0, 2, 28)` | Диапазон с обычным или заданным шагом |
| `M := [1, 2; 3, 4]`, `M[1, 0] =` | Матрица и индексирование |

Нажмите «Сохранить копию…» или Ctrl+S и укажите новое имя с расширением
`.xmcd`. В копию записываются изменённые формулы и числовые входы.
Исходный и другие существующие файлы сохраняются. Старые результаты
вычислений удаляются из изменённой копии, чтобы её можно было пересчитать.

## Консоль

Консольная утилита находится в папке `console`. Встроенный пример показывает расчёт
давления под опорой. Команда `set 2 60` изменяет нагрузку с 40 до 60 кН,
а давление с 1 до 1,5 МПа. Звёздочкой отмечены входы, доступные для изменения.

Чтобы открыть свой лист, выполните в PowerShell из папки архива

```powershell
.\console\list-rs.exe "C:\путь\расчёт.xmcd"
.\console\list-rs.exe "C:\путь\расчёт.xmcd" --check
```

`--once` выполняет полный расчёт без интерактивного режима. `--check` дополнительно
сверяет численные значения с полями `result`, сохранёнными в XML. Эталонные
значения используются только для сверки. Код завершения 0 означает успешный
расчёт обработанных формул и, для `--check`, успешную сверку. Код 1 означает
ошибку запуска или импорта, код 2 — ошибки вычислений или неполную сверку.

| Команда | Действие |
|---|---|
| `list` | Показать текст и результаты по регионам |
| `set 2 60`, `set 2 60000 N` | Изменить числовой вход с исходной или заданной единицей |
| `reset 2` | Вернуть исходный вход |
| `show 49` | Показать массив целиком по номеру региона |
| `plot Xr Yr roots.html` | Сохранить координатный график из двух векторов |
| `plotc w roots.html` | Сохранить комплексный вектор на плоскости Re–Im |
| `bench 2 40 60` | Сравнить полный и зависимый пересчёт в Rust |
| `quit` | Выйти |

Для графика вместо имени переменной можно указать номер региона. HTML открывается
локально в браузере. Доступны подписи координат при наведении, соединение точек
и одинаковый масштаб осей. Для координат с размерностями используются значения
в базовых единицах СИ. Изменения входов действуют до выхода из программы.

## Расчёты

- Действительные и комплексные числа, арифметика, степени, корни, модуль,
  аргумент, сопряжение, действительная и мнимая части, экспонента и логарифмы,
  тригонометрические и обратные тригонометрические функции.
- Пользовательские функции с выражениями и несколькими аргументами, сравнения,
  логические операции и условная функция `if`. При импорте ссылки привязываются
  к определениям, доступным выше по листу, включая ссылки в теле функции.
- Векторы и матрицы, диапазоны, индексация и присваивание по индексам,
  `ORIGIN`, транспонирование, арифметика, `sum`, `mean`, `identity`,
  определитель, обратная матрица и `lsolve` для безразмерных коэффициентов.
- Основные единицы СИ и отдельные внесистемные единицы. Числа хранятся
  в `f64` и выводятся с точностью до 12 значащих цифр.

На трёх приложенных листах с комплексными числами совпали все
62 сохранённых численных результата. Каждый лист вычислил 29 корней.
В графическом приложении проверен импорт трёх встроенных X–Y-графиков из
`Complex_numbers_variant_24_calculations.xmcd`. Поддерживаются также
параметрические, полярные, поверхностные и контурные графики на новых листах.
Добавлены численный анализ, нелинейные решатели, ОДУ, программные регионы и
базовая символика. Их покрытие и ограничения описаны в [STATUS.md](STATUS.md).
Тест скорости сравнивает режимы Rust-движка на одном листе.

## Сборка из исходников

Стабильный Rust и инструменты C++ для Visual Studio позволяют выполнить

```powershell
cargo test --features desktop --all-targets --locked
cargo build --release --features desktop --bins --locked
```

Готовый файл в архиве собран со статической библиотекой времени выполнения MSVC.

Для проверки совместимости на трёх листах запустите из корня проекта

```powershell
.\scripts\verify.ps1
```
